# P-실무프로젝트

가천대학교 스마트시티학과 · 2026학년도 2학기 · **3주 집중 프로젝트 과정**

캡스톤디자인을 수강한 학생은 기존 주제를 이어갈 수 있습니다. 이 경우 기존 대시보드에 주제와 관련된 AI 에이전트 기능을 추가합니다. 새 주제로 진행하는 학생은 팀을 구성해 주제를 선정합니다. 최종 발표에서는 프로젝트 결과를 설명하고 주제에 맞는 Agentic AI 시스템을 제안합니다.

수업 발표는 컨버전스 데이 최종 발표 1회입니다. 팀원 전원이 A4 반 장 크기의 메모지 한 장으로 대본 없이 발표하며 청중과 시선을 맞춥니다. 중간에는 팀별 미팅에서 팀원 각자가 진행 상황을 공유합니다.

종강까지 매주 미팅을 Zoom으로 녹화하고 링크를 구글챗에 제출합니다. 개인 프로젝트 학생은 지정 조교와 매주 미팅합니다.
